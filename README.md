# ✨ HubSpot Markdown Paster

A userscript that lets you **paste Markdown directly into HubSpot's rich-text editor** — no manual formatting needed.

## 🧪 Browser Compatibility

- ✅ **Works great in Firefox** via [Tampermonkey](https://www.tampermonkey.net/)
- ⚠️ **Chrome support is TODO** – latest Chrome versions seem to block userscripts from loading on HubSpot.

---

## 🚀 Installation

1. **Install Tampermonkey** (userscript manager extension):
   - [🦊 Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
   - [🧭 Chrome Extension](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

2. **Install the script**:
   - Go to [the userscript page](https://github.com/avallete/hubspot-markdown-paster)
   - Click the **raw** button on `hubspot-markdown-paste.user.js`
   - Tampermonkey should prompt you to install it.

---

## 📝 Usage

1. **Copy** some Markdown (e.g. from your editor or docs).
2. Go to **any HubSpot rich-text editor** (like emails, notes, blog posts, etc.).
3. Hit the shortcut: `Cmd+Shift+0` (or `Ctrl+Shift+0` on Windows).
4. **Tadaa!** 🎉 Your Markdown is magically pasted and formatted.
